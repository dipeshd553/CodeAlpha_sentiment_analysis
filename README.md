# Sentiment Analysis and Emotion Detection on Amazon Reviews

## Project Overview

This project focuses on performing Sentiment Analysis and Emotion Detection on Amazon product reviews using Natural Language Processing (NLP) techniques. The main objective is to analyze customer opinions, identify sentiment patterns, detect emotions, and generate meaningful business insights from textual review data.

---

# Objectives

- Perform sentiment classification on customer reviews.
- Detect emotions expressed in customer feedback.
- Analyze customer behavior and product perception.
- Visualize sentiment trends using graphs and word clouds.
- Generate business insights from review data.

---

# Dataset Information

The dataset contains Amazon product reviews with the following attributes:

- Product ID
- Product Title
- Product Price
- Review User ID
- Review Profile Name
- Review Helpfulness
- Review Score
- Review Time
- Review Summary
- Review Text

Dataset Size:
- 252,056 rows
- 10 columns

# Project Workflow

## 1. Data Preprocessing
- Checked dataset information
- Handled missing values
- Removed duplicate records
- Converted datatypes
- Cleaned review text

## 2. Exploratory Data Analysis (EDA)
- Review score distribution
- Product popularity analysis
- Review length analysis
- Monthly and yearly review trends

## 3. Sentiment Analysis
Reviews were classified into:
- Positive
- Negative
- Neutral

Sentiment mapping was performed using review scores:
- 4–5 → Positive
- 3 → Neutral
- 1–2 → Negative

## 4. Emotion Detection
Detected emotions include:
- Happy
- Sad
- Angry
- Fear
- Surprise
- Neutral

## 5. Visualizations
The following visualizations were created:
- Sentiment Distribution
- Review Score Distribution
- Emotion Distribution
- Word Clouds
- Review Length Distribution
- Time Trend Analysis
- Frequent Words Analysis

# Key Findings

- Most customer reviews were positive.
- 5-star ratings dominated the dataset.
- Customers frequently appreciated product quality and effectiveness.
- Negative feedback mainly related to smell, packaging, and product issues.
- Customer engagement increased significantly over time.

---

# Business Insights

- Positive customer feedback indicates strong product acceptance.
- Negative reviews help identify improvement areas.
- Trend analysis helps businesses understand customer behavior.
- NLP analysis can support marketing and product development strategies.
